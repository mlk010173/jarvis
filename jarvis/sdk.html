SDK do JARVIS

Integre o chat com IA, as ferramentas reais e o modo Agente (que pesquisa na internet) em qualquer site ou app seu com poucas linhas.

← InícioAbrir o app

1. Inclua o SDK

<script src="https://mlk010173.github.io/jarvis/jarvis/jarvis-sdk.js"></script>

2. Conecte e use as ferramentas reais (sem IA)

const jv = new JarvisSDK({ token: 'SEU_TOKEN' }); // entre com jv.entrar(email, senha)

const clima = await jv.clima('Vitória');
const dolar = await jv.moeda('USD', 'BRL');
const btc   = await jv.cripto('bitcoin');
const busca = await jv.pesquisar('notícias de hoje');
const moto  = await jv.abrir('https://exemplo.com/pagina');
const news  = await jv.noticias(); // manchetes do Brasil agora

3. Chat com IA + modo Agente

A conta conecta a própria IA em Minhas IAs (Google Gemini tem plano grátis). Com o modo agente, a IA pesquisa na internet e abre páginas sozinha quando precisa.

const p = await jv.criarProjeto('Atendimento', 'Responda com simpatia.', 'JARVIS');
const r = await jv.chat([{ role: 'user', content: 'qual o dólar hoje e a previsão?' }], p.id, 'agente');
console.log(r.resposta, r.ia_nome);

4. MCP: catálogo e execução de ferramentas

const cats = await jv.ferramentas();       // lista de ferramentas com esquemas
const r = await jv.executar('pesquisar', { q: 'github jarvis' });
