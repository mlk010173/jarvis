Primeiros passos

Estes tutoriais são para quem nunca mexeu com IA ou programação. Siga na ordem. Cada passo leva poucos minutos.

1. Criar a sua conta
  1. Clique em Criar conta grátis.
  2. Preencha seu nome, e-mail e uma senha com pelo menos 8 caracteres.
  3. Clique em "Criar minha conta grátis". Você já entra no painel.

Para voltar depois, use "Entrar" com o mesmo e-mail e senha.

2. Conectar uma IA grátis (Gemini)

A "IA" é o cérebro do assistente. Você usa a sua própria conta, e o Gemini do Google tem plano grátis.

  1. No painel, clique em Minhas IAs.
  2. No cartão "Gemini (Google)", clique em Pegar a chave →. Abre o site do Google.
  3. Entre com sua conta Google e clique em Create API key.
  4. Copie a chave (um código longo que começa com AIza).
  5. Volte ao painel, cole no campo do Gemini e clique em Conectar.
  6. Se aparecer "Funcionando", deu certo.

Dica: conecte também o Groq e o OpenRouter (grátis). Se uma IA atingir o limite, a outra responde no lugar.

3. Criar um projeto

Um projeto é um assistente com nome e jeito próprios. Você pode ter vários: um para atender clientes, outro para criar posts...

  1. Em Meus projetos, escreva um nome (ex.: "Atendimento da loja").
  2. Clique em Criar projeto. Você vai para a tela dele.
4. Escrever boas instruções

As instruções são o "treinamento" do assistente. Escreva como se estivesse explicando o trabalho para um funcionário novo.

Modelo para copiar e adaptar:

Você é a Luna, atendente da Loja X, que vende keys de jogos Steam.
Seja educada, simpática e responda em poucas frases.

O que você sabe:
- A entrega é automática, logo após o pagamento, no e-mail do cliente.
- Pagamento por PIX ou cartão.
- Garantia de 7 dias se a key não funcionar.
- Suporte humano: WhatsApp (11) 99999-9999, das 9h às 18h.

Regras:
- Nunca invente preços ou promoções. Se não souber, mande o link da loja.
- Se o cliente estiver bravo, peça desculpas e passe o WhatsApp do suporte.

Cole no campo Instruções da aba "Configurar" e clique em Salvar alterações.

5. Testar o assistente
  1. Abra a aba Testar do projeto.
  2. Escreva perguntas que seus clientes fariam e veja as respostas.
  3. Não gostou de alguma? Volte em "Configurar", ajuste as instruções e teste de novo.

Embaixo de cada resposta aparece qual IA respondeu (ex.: "via Gemini").

Usar fora do painel

6. Gerar uma chave de API

A chave de API é uma senha que deixa outro programa (seu site, bot, automação) falar com o assistente.

  1. No projeto, abra a aba Chaves de API.
  2. Dê um nome (ex.: "Bot do Discord") e clique em Gerar nova chave.
  3. Copie na hora: por segurança ela só aparece uma vez.
  4. Guarde num lugar seguro. Se vazar, clique em Revogar e gere outra.
7. Colocar no site ou num bot

Essa parte normalmente é feita por quem cuida do seu site ou bot. Mande para essa pessoa:

  • A chave de API que você gerou.
  • O link da Documentação da API (tem exemplos prontos, inclusive de bot do Discord).

Se você mesmo for fazer, comece pelo exemplo "cURL" da documentação: dá para testar só copiando e colando no terminal.

Deu problema?

"Nenhuma IA conectada"
Faça o tutorial 2 e conecte pelo menos uma IA.
"Todas as IAs conectadas falharam"
Em "Minhas IAs", clique em "Testar" em cada uma. Chave errada? Cole de novo. Limite grátis acabou? Conecte outra IA como reserva.
"Limite diário do plano atingido"
Você usou todos os pedidos de hoje. O contador zera à meia-noite.
"Chave de API inválida ou revogada"
A chave foi digitada errada, falta o "Bearer " antes dela, ou ela foi revogada. Gere outra.
As respostas estão ruins
Melhore as instruções (tutorial 4): seja específico, dê exemplos e diga o que ele NÃO deve fazer.

Glossário

IA (Inteligência Artificial)
Programa que entende e escreve texto, como o ChatGPT e o Gemini.
Projeto
Um assistente seu, com nome, instruções e chaves próprias.
Instruções
O texto que diz ao assistente quem ele é e como deve responder.
API
Uma "porta" para outros programas conversarem com o seu assistente.
Chave de API
A senha dessa porta. Quem tem a chave consegue usar o seu assistente.
Modelo
A versão da IA (ex.: gemini-2.5-flash). Pode deixar o padrão.
Token
Pedacinho de texto que as IAs usam para medir o tamanho das mensagens.
